Main goal:
If a patient is already taking a supplement and the related lab marker is currently optimal, the system should still acknowledge it as a “continue current regimen” recommendation, even if the engine would not normally recommend it because the value is already optimal.

Example:
If Vitamin D = 80 ng/mL and the patient is taking Vitamin D3 5000 IU daily, do not recommend “start Vitamin D.” Instead add:
“Vitamin D3 — Continue current regimen. Your Vitamin D level is currently optimal at 80 ng/mL while taking Vitamin D3 5000 IU daily. Continue your current regimen unless your provider recommends a dose change.”

Requirements:
1. Do not modify the core supplement scoring algorithm.
2. Add this only after normal supplement recommendations are generated.
3. Add continuationOnly?: boolean and continuationNote?: string as optional fields.
4. continuationOnly items should not affect scoring, ranking, phenotype logic, or abnormal-lab logic.
5. Prevent duplicates. If Vitamin D is already recommended by the engine, annotate the existing recommendation instead of adding a second one.
6. Only create continuation-only recommendations when:
   - the patient is currently taking the supplement,
   - the related lab marker is optimal,
   - and the supplement was not already recommended by the engine.
7. Use conservative wording. Do not say the supplement “caused” the optimal lab. Say the level is optimal “while taking” the supplement.
8. For supplements without a reliable lab marker, do not create continuation-only recommendations.
9. Make all UI/PDF/portal rendering backward-compatible with optional fields and safe fallbacks.
10. Apply only to the female and male evaluation supplement flows for now.
