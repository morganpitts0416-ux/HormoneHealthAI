Add a medication normalization service that helps ClinIQ identify medications more accurately before they are used by downstream features like transcription review, SOAP generation, medication reconciliation, future e-prescribing, and future FHIR interoperability.

This should not change the SOAP note style or behavior unless a medication match is high-confidence and only improves the medication identity. Current SOAP rules must remain intact.

Implementation request:

1. Create a medication normalization layer using RxNorm concepts.

   * Map brand names to generic names.
   * Map generic names to RxNorm identifiers when available.

   * Store the normalized medication separately from the original text.

2. Add confidence scoring.

   * High confidence: exact or near-exact match to medication name/brand/generic.
   * Medium confidence: possible match but needs review.

   * If a medication could be confused with a look-alike/sound-alike medication, do not silently choose.

     “Medication requires provider review: possible matches include drospirenone vs risperidone.”

   * Discussed medications must remain discussed.

   * The SOAP writer may receive normalized medication metadata as supplemental context only.
